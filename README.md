# JPMC-Hackathon
# Data-Driven Expansion Strategy Tool

## Overview
1st place solution from the JPMorgan Chase Data for Good Hackathon. An end-to-end analytics system that processes nonprofit datasets into decision-ready insights to support scalable expansion strategy.

## System Design
- Modular data ingestion and preprocessing
- Structured data transformations and feature analysis
- Insight generation via exploratory analytics
- Visualization layer for stakeholder-facing outputs

## Tech Stack
Python, Pandas, NumPy, Data Visualization, Analytics Pipelines

## Engineering Contributions
- Designed and implemented the core data pipeline
- Structured reusable analysis modules for scalability
- Optimized data transformations for clarity and maintainability
- Bridged technical outputs with business requirements

## Results
Delivered a production-minded analytics solution under time constraints, enabling data-backed expansion decisions for a real nonprofit partner.
